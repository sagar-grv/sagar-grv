### In private development (releasing after review)

- **RAGLens**: a retrieval evaluation harness. It benchmarks how often retrieval ranks the right document for golden questions over a fixed corpus, and shows actionable failures in a plain-language dashboard. 15 tests passing.
- **Fine-tune Study Assistant**: a LoRA fine-tuning pipeline (Qwen2.5-0.5B) that aligns a small instruct model to a taught ML curriculum, with held-out evaluation and documented limits. An early learning project in fine-tuning, not a shipped specialty.
